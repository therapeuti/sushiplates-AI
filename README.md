**회전초밥 접시를 촬영하면 AI가 자동으로 인식하여 결제금액을 계산하는 시스템입니다.**

객체 탐지 모델 YOLO 기반 실시간 초밥접시 감지 및 가격 계산 웹 애플리케이션으로, 카메라를 통해 초밥 접시를 자동으로 인식하고 가격을 계산합니다. 직원이 접시를 일일이 계산하는 것에 비해 **훨씬 빠르고 정확한 결제 처리(10초 이내)**가 가능합니다.

## 🎯 해결하고자 하는 문제

### 문제점
초밥 식당에서는 손님이 먹은 접시를 직원이 일일이 하나하나 계산해야 하므로 **시간이 오래 걸립니다**.

### 기존 해결책의 한계
RFID를 이용한 자동 계산 시스템도 있지만 **높은 도입 비용**이 발생합니다.

### 우리의 솔루션
**AI 비전 기술**을 활용하여 빠르고, 정확하고, 간편하게 접시를 자동으로 인식하고 계산하는 시스템을 구축합니다.

## 🧠 기술적 도전 및 해결 과정

### 1️⃣ 실시간 추론 지연 및 정확도 문제 극복

**문제점**
- 초기 개발 단계에서 Flutter 기반 앱에 YOLO 모델을 임베딩하려 했으나, 실시간 추론 시 긴 지연 시간과 낮은 정확도 이슈 발생
- 모바일 환경에서의 GPU 리소스 제한으로 인한 성능 저하

**탐색 과정**
- YOLO 데이터셋 증가 및 하이퍼파라미터 튜닝을 통한 정확도 개선 시도
- YOLOv5, YOLOv8n, YOLOv8s 등 다양한 모델 벤치마킹
- 온디바이스(On-Device) 추론 vs 서버 기반 추론 아키텍처 비교 분석

**해결책**
- **FastAPI + WebSocket** 기반 서버 아키텍처로 전환
- 비동기 이미지 처리를 위해 **ThreadPoolExecutor** 활용한 병렬 처리
- 최적의 모델로 **YOLOv8s** 선택
  - 추론 정확도: 90% 이상
  - 추론 지연: 1초 이내
  - 캡처부터 결제 완료까지: 최대 10초

**핵심 구현**
```python
# WebSocket을 통한 실시간 비동기 추론
results = await asyncio.to_thread(process_image, image_data, model_name)
await manager.send_inference_results(websocket, results)
```

### 2️⃣ UX 중심의 빠른 결과 검증 설계

**문제점**
- 추론 결과를 사용자가 빠르게 확인하고 수정해야 하는데, UI/UX 설계가 복잡할 경우 전체 결제 시간 증가

**해결책**
- **색상 코딩 시스템**: 각 접시 색상(검정, 회색, 흰색, 초록, 분홍, 노랑 등)과 일치하는 라벨 표시로 한눈에 검증 가능
- **빠른 수정 인터페이스**: 한 두 번의 터치만으로 감지된 접시 추가/삭제/수정 가능
- **반응형 디자인**: 모바일, 태블릿, 데스크톱 전 기기에서 최적화된 인터페이스 제공
  - CSS Grid/Flexbox를 활용한 동적 레이아웃
  - 모바일(480px~767px), 태블릿(768px~1023px), 데스크톱(1024px+) 모두 지원

**결과**
- 직원들이 추론 결과를 실시간 카메라 화면에서 즉시 검증 가능
- 불일치 시에도 빠르게 수정하여 사용자 경험 극대화
- 초밥 식당의 실제 운영 환경에 맞는 UX 구현
